# electrochemistry-bluesky

Bluesky control of battery experiments on a Keithley 2460: run sheets,
QueueServer, HDF5 run files and a synthetic-cell simulator, on top of
[keithley2460-ophyd](https://github.com/BAMresearch/keithley2460_ophyd).
